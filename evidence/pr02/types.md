# ПР02 — типы сообщений

## `/turtle1/cmd_vel`

- Тип: `geometry_msgs/msg/Twist`.
- Назначение: входной топик команд скорости для `/turtlesim`.
- В опыте `/turtlesim` являлся подписчиком.

`Twist` состоит из двух векторов `geometry_msgs/msg/Vector3`:

```text
Vector3 linear
  float64 x
  float64 y
  float64 z
Vector3 angular
  float64 x
  float64 y
  float64 z
```

Для плоского движения turtlesim используются:

- `linear.x` — скорость движения вперёд или назад;
- `angular.z` — скорость вращения вокруг вертикальной оси;
- остальные компоненты в этой работе равны нулю.

Команда `{linear: {x: 1.0}, angular: {z: 0.5}}` задаёт движение вперёд и положительное вращение против часовой стрелки.

## `/turtle1/pose`

- Тип по фактическому выводу Jazzy: `turtlesim/msg/Pose`.
- Назначение: выходной топик текущего состояния черепахи.
- В опыте `/turtlesim` являлся издателем.

Основные поля `Pose`:

- `x`, `y` — координаты на поле симулятора;
- `theta` — ориентация в радианах;
- `linear_velocity` — текущая линейная скорость;
- `angular_velocity` — текущая угловая скорость.

Ошибочный `/cmd_vel` имел тот же тип `geometry_msgs/msg/Twist`, но являлся другим полным именем. Поэтому издатель обнаруживался отдельно и не соединялся с подписчиком `/turtlesim` на `/turtle1/cmd_vel`.
