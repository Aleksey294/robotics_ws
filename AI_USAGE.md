# Декларация использования ИИ

## PR01

- **Модель и инструмент.** Для подготовки работы использовался OpenAI Codex.

- **Назначение.** Codex помог уточнить смысл команд ROS 2 и привести в понятный вид описание нод, топиков и изоляции через `ROS_DOMAIN_ID`.

- **Оформление.** С его помощью были отредактированы `README.md` и `evidence/pr01/graph.md`, подготовлена структура GitHub Actions и проверено заполнение `environment.json` и `report.json`.

- **Проверка результата.** Содержание отчёта сверялось с данными из `doctor.txt`, `pose-broken.txt` и `pose-fixed.txt`. Дополнительно проверялись версии окружения, коды завершения, формат JSON и наличие обязательных файлов.

- **Границы использования.** ИИ применялся для пояснений, редактирования и проверки структуры материалов. Наблюдения в отчёте не заменялись придуманными значениями. В `report.json` указано `ai_used: true`.
